Viktige valg og ting jeg lærte
- Arbeidsflyten i git: clone -> stage -> commit -> push. Commit-meldingen skrives
  før man klikker Commit.
- Git-e-posten må stemme med GitHub-kontoen, ellers blir ikke commitene knyttet
  til meg.
- VS Code må bruke riktig Python-tolk, ellers finner den ikke pakkene som er
  installert i Anaconda.
- Filnavnet til output hentes fra config.yml og skrives ikke rett inn i koden.
- Boolsk filtrering i pandas skjer i to deler: først en True/False-serie, så
  plukkes radene med True ut.
- print-linjene var bare for å teste hvert steg underveis. Det oppgaven krever er
  JSON-filen.
- Å teste ett steg om gangen med print gjør feil lettere å finne.
